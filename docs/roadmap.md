# ΦPRESS Roadmap

## Rung 0 · Public concept and safety boundaries
- [x] Public repository and project charter
- [x] Distinguish cleaning from deodorizing/pressing
- [x] Document physically plausible components and unknowns

## Rung 1 · Browser research bench (this pull request)
- [x] Static online experience with no backend or subscriptions
- [x] Reproducible illustrative particle transport and tunable controls
- [x] Automated model-invariant tests
- [x] Initial architecture, hazards, and E0 experimental design
- [ ] Manually enable GitHub Pages for online access after merging

## Cabinet C0.2 · ClosetVault / Φ-Midifier / battery feasibility
- [x] Slim closet cabinet architectural concept (not validated dimensions)
- [x] Separation of low-energy garment preservation from active wet cleaning and hot drying
- [x] Distinct optional Φ-Midifier acoustic/vibration research module, not mistaken for a humidifier
- [x] Interactive battery energy calculator with peak-power feasibility gate
- [ ] Measured temperature/RH/condensation and standby-energy dataset
- [ ] Dedicated isolation, ventilation and thermal safety review before an actual closet installation

## Cabinet C0.3 · Explainable advisory supervisor
- [x] Local-first pure deterministic model with typed, bounded snapshots
- [x] Door, leak, ventilation, collection tank, treatment isolation and fabric-assessment checks
- [x] Dew-point warning and high-RH policy scenarios (provisional only)
- [x] Mains-only gate for wet cleaning and thermal finishing; watt + watt-hour checks for battery modes
- [x] Explainable receipt UI, scenario presets and automated invariants tests
- [ ] Bench calibration and independent safety-rated hardware protections; model cannot control a product

## Cabinet C0.4 · Reduced-order moisture and energy digital twin
- [x] Browser-based 24–72 hour study with fixed 10-minute simulation steps
- [x] Water mass conservation across cabinet air, garments, outside exchange, surfaces and collection tank
- [x] Explicit fan internal recirculation (not dehumidification) and illustrative AC-only water recovery
- [x] Energy budget and finite battery depletion without negative charge
- [x] High-RH and cold-surface condensation tracking, with CSV and JSON exports
- [x] Determinism, bookkeeping and failure-path tests
- [ ] Calibrate evaporation, ACH, heat balance and condensation from real measured data
- [ ] Add real heat rejection, sensor uncertainty and surface moisture re-evaporation models

## Cabinet C0.5 · Modular fixture and cartridge feasibility bench
- [x] Interactive dimensional packaging study for shirt, hat and shoe fixtures
- [x] Declarative, versioned fixture manifests for candidate mounts and modes
- [x] Separately described dry circulation, nested wetting, dirty-water recovery and thermal conditioning paths
- [x] Guard receipts for geometry, compatibility, material review, leaks, service access and wet-bay isolation
- [x] Transparent assumed cycle power, sequential energy, water dose and battery peak gates
- [x] Exportable study receipts and conceptual module BOM, with deterministic tests
- [ ] Physical mockup of garment envelope, door swing and service access
- [ ] Measured moisture/soil extraction, peak power, ventilation heat rejection and fabric tolerance
- [ ] Independent formal safety analysis for any energized prototype

## Rung 2 · Credible numerical exploration
- [ ] Establish conservation-based equations, not arbitrary efficiency scoring
- [ ] Compare vortex geometries and a simple-jet baseline
- [ ] Model suction, wetting, and realistic textile boundary conditions
- [ ] Track uncertainty, sensitivity, power, and failure modes
- [ ] Independent review of model assumptions

## Rung 3 · Benchtop evidence E0
- [ ] Registered protocol and independent specimens
- [ ] Independent measurement of water, soil, textile damage, and energy
- [ ] Controlled A–F experiment matrix
- [ ] Publish full data, null outcomes, and analysis
- [ ] Decide whether BubbleGear geometry is worth complexity

## Rung 4 · Appliance subsystem feasibility
- [ ] Modular garment holder and protected collection system
- [ ] Controlled moisture transfer and drying/pressing tests
- [ ] Material compatibility matrix for shirts, hats and shoes
- [ ] Independent thermal/electrical/pressure safety design

## Rung 5 · Integrated prototype
- [ ] Formal hazard analysis and qualified design reviews
- [ ] Safety-rated interlocks and independent hardware shutoffs
- [ ] Cleaning-validation and garment durability benchmarks
- [ ] Water/energy/labor comparison to a washer + dryer + press
- [ ] Open repair manuals and component interfaces

### Not yet promised
Instant cleaning, no detergent for all soils, sanitation, universal fabric compatibility, regulated-product readiness or replacement of washer/dryer for every load.

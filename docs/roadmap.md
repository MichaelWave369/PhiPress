# ΦPRESS Roadmap

## Rung 0 · Public concept and safety boundaries
- [x] Public repository and project charter
- [x] Distinguish cleaning from deodorizing/pressing
- [x] Document physically plausible components and unknowns

## Rung 1 · Browser research bench (this pull request)
- [x] Static online experience with no backend or subscriptions
- [x] Reproducible illustrative particle transport and tunable controls
- [x] Automated model-invariant tests
- [x] Initial architecture, hazards, and E0 experimental design
- [ ] Manually enable GitHub Pages for online access after merging

## Rung 2 · Credible numerical exploration
- [ ] Establish conservation-based equations, not arbitrary efficiency scoring
- [ ] Compare vortex geometries and a simple-jet baseline
- [ ] Model suction, wetting, and realistic textile boundary conditions
- [ ] Track uncertainty, sensitivity, power, and failure modes
- [ ] Independent review of model assumptions

## Rung 3 · Benchtop evidence E0
- [ ] Registered protocol and independent specimens
- [ ] Independent measurement of water, soil, textile damage, and energy
- [ ] Controlled A–F experiment matrix
- [ ] Publish full data, null outcomes, and analysis
- [ ] Decide whether BubbleGear geometry is worth complexity

## Rung 4 · Appliance subsystem feasibility
- [ ] Modular garment holder and protected collection system
- [ ] Controlled moisture transfer and drying/pressing tests
- [ ] Material compatibility matrix for shirts, hats and shoes
- [ ] Independent thermal/electrical/pressure safety design

## Rung 5 · Integrated prototype
- [ ] Formal hazard analysis and qualified design reviews
- [ ] Safety-rated interlocks and independent hardware shutoffs
- [ ] Cleaning-validation and garment durability benchmarks
- [ ] Water/energy/labor comparison to a washer + dryer + press
- [ ] Open repair manuals and component interfaces

### Not yet promised
Instant cleaning, no detergent for all soils, sanitation, universal fabric compatibility, regulated-product readiness or replacement of washer/dryer for every load.
